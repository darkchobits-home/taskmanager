# Task Manager – Backend

Application de gestion de tâches développée en Java / Spring Boot.

## 🎯 Objectif

Ce projet personnel me permet de mettre en pratique :
- La conception d’API REST
- L’architecture en couches (Controller / Service / Repository)
- La gestion des exceptions
- La validation des données
- Les bonnes pratiques Spring Boot
- Les tests unitaires

## 🛠 Stack technique

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- JUnit

## 🏗 Architecture

Architecture classique en couches :
- Controller
- Service
- Repository
- DTO / Mapper
- Gestion centralisée des exceptions

```bash
mvn clean install
mvn spring-boot:run
